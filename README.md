# Experience Media - Dual-Currency Accounting & Project Workflow Dashboard

لوحة تحكم تفاعلية متكاملة لإدارة الحسابات وتتبع مشاريع شركات الدعاية والإعلان بالعملة المزدوجة (الجنيه السوداني SDG / الجنيه المصري EGP).

## الميزات الرئيسية

- **دعم العملة المزدوجة اللحظي**: تحويل وتقويم المبالغ بين SDG و EGP بناءً على سعر الصرف اليومي القابل للتعديل المباشر.
- **تثبيت أسعار الصرف التاريخية للدفعات**: حفظ سعر الصرف اللحظي لكل دفعة محصلة (Historical Exchange Rate Locking) لضمان دقة القوائم المالية.
- **سجل المصروفات والتكاليف**: دعم تسجيل التكاليف بالعملتين وتحديث قيمها المعادلة فورياً.
- **تحليل حساسية سعر الصرف (FX Sensitivity Matrix)**: جدول ورسم بياني تفاعلي يوضح تأثير تقلبات سعر الصرف على صافي الربح وهامش الربح للدفعة المتبقية مع تحديد نقطة التعادل (278.7 ج.س/ج.م).
- **متابعة مراحل العمل (Workflow Tracker)**: إدارة وتتبع مراحل تنفيذ مشروع الدعاية والإعلان الست وحساب نسبة الإنجاز تلقائياً.
- **حفظ تلقائي (localStorage)**: حفظ كافة البيانات والتعديلات تلقائياً على متصفح المستخدم.

## البيانات الافتراضية للمشروع (PRJ-001)

- **العميل**: شركة تينز
- **الخدمة**: تنفيذ 1000 تيشيرت مطبوع
- **قيمة التعاقد**: 31,000 ج.س للقطعة × 1000 = 31,000,000 ج.س
- **الدفعة الأولى المحصلة**: 14,000,000 ج.س بسعر صرف ثابت 175 = 80,000 ج.م
- **المبلغ المتبقي**: 17,000,000 ج.س (تقوّم بسعر اليوم)
- **إجمالي التكلفة**: 141,000 ج.م (مصنع 130,000 ج.م + شحن 11,000 ج.م)
- **العجز النقدي الحالي لسداد المصنع والشحن**: 61,000 ج.م
