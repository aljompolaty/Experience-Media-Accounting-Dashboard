# Experience Media - Accounting & Project Workflow Dashboard

نظام حسابات وإدارة مشاريع لشركة اكسبيرينس ميديا للدعاية والإعلان، بالجنيه السوداني (SDG) والجنيه المصري (EGP) والدولار (USD). عملة التقارير هي الجنيه المصري.

## الميزات الرئيسية

- **تعدد المشاريع**: لوحة عامة تجمع كل المشاريع (المحصل، المتبقي، التكاليف، الربح، النقد)، وصفحة تفصيلية لكل مشروع.
- **العملاء والموردون**: أرصدة كل عميل ومشاريعه، وحسابات الموردين (الفواتير، المسدد، المتبقي، أقرب استحقاق) مع تسجيل السداد الجزئي.
- **ثلاث عملات بأسعار مثبتة**: كل دفعة ومصروف يحفظ سعر الجنيه المصري وسعر الدولار يوم تسجيله، فلا تتغير القيم التاريخية مع السوق.
- **سجل أسعار الصرف اليومي**: رسم لتطور السعر، وتعرّض كل مشروع لسعر الصرف، وتنبيه عند اقتراب السعر من نقطة تعادل أي مشروع بنسبة يحددها المستخدم.
- **التدفق النقدي المتوقع**: الرصيد من اليوم مع الدفعات المجدولة من العملاء والمستحقات غير المسددة للموردين، وتاريخ أول عجز متوقع.
- **عروض الأسعار وكشوف الحساب**: مستندات بهوية الشركة تُطبع أو تُحفظ PDF من المتصفح، وتحويل العرض المقبول إلى مشروع بضغطة.
- **قوالب مراحل التنفيذ**: قالب لكل نوع خدمة (طباعة، فيديو، لوحات إعلانية...) قابل للتعديل، ولكل مرحلة مسؤول وموعد نهائي.
- **تحليل حساسية سعر الصرف ونقطة التعادل** لكل مشروع، محسوبة تلقائياً.
- **مزامنة سحابية بين الأجهزة (Supabase)**: كل جهاز يعمل محلياً ودون إنترنت، ويرفع تعديلاته عند الاتصال. لا يكتب جهاز فوق تعديلات جهاز آخر بصمت، ونسخة أمان يومية تلقائية في السحابة. الإعداد في [SUPABASE_SETUP.md](SUPABASE_SETUP.md).
- **سجل التغييرات**: كل إضافة وتعديل وحذف مع وقته والجهاز، مع بحث.
- **تطبيق قابل للتثبيت (PWA)**: يُثبَّت على الجوال والكمبيوتر ويعمل دون إنترنت.
- **واتساب**: إرسال كشف حساب المشروع أو عرض السعر للعميل مباشرة.
- **تصدير Excel / Google Sheets**: ملف بأوراق منظمة (المشاريع، الدفعات، المصروفات، التدفق النقدي، ...).
- **نسخ احتياطي**: تنزيل كل البيانات كملف JSON واستيرادها على جهاز آخر.
- **هوية اكسبيرينس ميديا**: الشعار الرسمي، وخط ثمانية، والأزرق #00ADEF مع الجرافيت، ووضع فاتح وداكن.

## الملفات

- `index.html`: هيكل الصفحة.
- `css/app.css`: التصميم وتنسيقات الطباعة.
- `js/util.js`: التنسيق والأدوات المشتركة.
- `js/store.js`: نموذج البيانات والترقية من الإصدارات السابقة والحفظ.
- `js/calc.js`: الحسابات المالية (ملخص المشروع، نقطة التعادل، التدفق النقدي، التنبيهات).
- `js/ui.js`: نافذة النماذج والمكوّنات والرسم البياني.
- `js/forms.js`: نماذج الإضافة والتعديل والحذف.
- `js/views.js`: الصفحات.
- `js/audit.js`: سجل التغييرات التلقائي.
- `js/sync.js`: المزامنة مع Supabase.
- `js/share.js`: واتساب وتصدير Excel.
- `js/print.js`: المستندات المطبوعة.
- `js/app.js`: التنقل والأحداث.
- `sw.js` و`manifest.webmanifest` و`icons/`: التطبيق القابل للتثبيت والعمل دون إنترنت.
- `supabase/schema.sql`: جداول قاعدة البيانات وقواعد الأمان.
- `brand/`: ملفات الشعار الرسمية (لا يُعاد رسمها).
- `fonts/`: خط ثمانية محلياً، دون الاعتماد على خدمة خارجية.

## البيانات

تُحفظ البيانات في متصفح المستخدم (localStorage). البيانات المحفوظة من الإصدارات السابقة تُرقّى تلقائياً إلى مشروع ضمن قائمة المشاريع دون فقدان شيء. المصروفات القديمة تبدأ كمستحقات غير مسددة لأن الإصدار السابق لم يكن يتتبع السداد.

## كيفية التشغيل

انشره عبر GitHub Pages (أو أي استضافة `https`). لا يحتاج أي تثبيت أو أدوات بناء. فتح `index.html` مباشرة من الجهاز يعمل أيضاً، لكن دون التثبيت كتطبيق والعمل دون إنترنت.

عند تعديل أي ملف CSS أو JS ارفع رقم الإصدار في مكانين معاً: `?v=` في روابط `index.html`، و`VERSION` في `sw.js`. بدون ذلك يستمر المتصفح في عرض النسخة القديمة المخزنة.
